Code Review: CPU-Auslastung in einer eigenen Funktion bewerten

Die Idee ist sehr gut: Du möchtest die Bewertung aus main() in eine eigene Funktion verschieben. Genau diese Trennung macht den Code leichter lesbar und später gut testbar. Aktuell verhindern jedoch einige Gültigkeitsbereichs- und Verzweigungsfehler die Ausführung.

"""OpsWatch CLI: Command-line tool for system monitoring."""

from cpu import cpu_load
from deployment import describe_deployment
from status import evaluate_status

CPU_WARNING_THRESHOLD = 80.0
CPU_INCREASED_THRESHOLD = 60.0


def evaluate_cpu_usage(cpu_workload: float) -> str:
    """Return a status message for the given CPU workload."""
    if cpu_workload > CPU_WARNING_THRESHOLD:
        cpu_msg = "Warning: High CPU load!"
    elif cpu_workload > CPU_INCREASED_THRESHOLD:
        cpu_msg = "CPU load: Increased"
    else:
        cpu_msg = "CPU load: Normal"

    return cpu_msg


def main() -> None:
    """Run the main program."""
    version = "0.1.0"
    status_code = 0

    deployment_status = describe_deployment(successful=True)
    status = evaluate_status(status_code)
    cpu_workload = cpu_load()
    cpu_msg = evaluate_cpu_usage(cpu_workload)

    print("OpsWatch CLI running!")
    print(f"Deployment: {deployment_status}")
    print(f"Version: {version}")
    print(f"Status: {status}")
    print(f"CPU load: {cpu_workload:.1f} %")
    print(cpu_msg)


if __name__ == "__main__":
    main()

Die Funktion kennt nur ihren Parameter cpu_load. cpu_workload wurde dagegen ausschließlich innerhalb von main() definiert.

Variablen innerhalb einer Funktion sind normalerweise nur in dieser Funktion verfügbar:

main()

evaluate_cpu_usage()

Der Name evaluate_cpu_usage beschreibt außerdem genauer, was die Funktion macht: Sie misst die CPU nicht, sondern bewertet einen bereits gemessenen Wert.
